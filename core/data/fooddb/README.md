# FitAI food database

The offline food database the app ships with: `../src/commonMain/composeResources/files/foods.json`
(about 300 foods). It is generated by `build_foods.py` in this folder; edit the table there and run
`python3 core/data/fooddb/build_foods.py`, never the JSON by hand. `FoodDatabaseTest` (core/data unit
tests) checks every entry and the starter diet built from it.

Read by `BundledFoodDataSource` (core/data), searched by `searchFoods` (core/domain, accent and Turkish
letter insensitive), and used by `StarterDiet` for the free / dev / fallback diet plans. Users add their
own foods on the device (`custom_foods` table, synced to `users/{uid}/custom_foods`).

## Entry format

| Key | Meaning |
|---|---|
| `id` | stable id, stored in diary entries and plans; never rename one that shipped |
| `tr`, `en` | display names |
| `cat` | category code (`FoodCategory` in core/domain) |
| `kcal`, `p`, `c`, `f`, `fiber` | per 100 g of the edible part: kcal, protein, carbohydrate (incl. fibre), fat, fibre in g |
| `s` | household servings, most common first: unit code (`FoodUnits`) and grams per unit; grams are always offered too |
| `tags` | diet flags: `meat`, `poultry`, `fish`, `shellfish`, `pork`, `dairy`, `egg`, `honey`, `gluten`, `alcohol`, `nuts` |
| `kw` | extra search words (accent-free spellings, other names) |
| `src` | where the values come from (below) |

Diet restrictions map to tags in `FoodItem.excludedTags` (vegan excludes meat, poultry, fish, shellfish, pork,
dairy, egg and honey; gluten-free excludes gluten; and so on). Oats are tagged `gluten` because regular oats
are usually cross-contaminated. Turkish sucuk, salam and pastırma are beef products and carry no `pork` tag.

## Sources

- **`usda`**: USDA FoodData Central, SR Legacy and FNDDS (https://fdc.nal.usda.gov/). Public domain (CC0 1.0),
  so the values may be redistributed. Values are rounded and taken for the closest matching food, for example
  "Cheese, feta" for beyaz peynir and "Bread, whole-wheat, commercially prepared" for tam buğday ekmeği.
- **`recipe`**: estimates for composite and Turkish dishes (menemen, mercimek çorbası, kuru fasulye, pilav,
  köfte, döner, lahmacun, pide, börek, sarma, baklava…). Each is computed from a standard home or esnaf
  lokantası recipe by summing USDA ingredient values and dividing by the cooked weight. Real dishes vary with
  oil and portion, so treat them as typical values.
- **`label`**: typical values from Turkish retail product labels for products USDA doesn't cover well
  (ayran, kaşar, tulum, lor, sucuk, pastırma, whey, lokum, tahin helvası…), averaged and rounded. No single
  brand's label is copied.

No values were taken from TürKomp or other databases with restrictive licences.

Household serving weights (dilim, su bardağı = 200 ml, çay bardağı ≈ 100 ml, yemek kaşığı, kase, porsiyon,
avuç ≈ 30 g…) follow common Turkish kitchen measures and USDA portion weights.
