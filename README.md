# FitAI
FitAI, kullanıcının kişisel verilerini (boy, kilo, yaş, hedef, ekipman erişimi, diyet kısıtlamaları) girerek AI destekli antrenman programı ve diyet planı oluşturduğu; bu programı takip edebildiği, fotoğraf check-in ile görsel ilerleme kaydettiği ve akıllı bildirimler aldığı bir fitness uygulamasıdır.
